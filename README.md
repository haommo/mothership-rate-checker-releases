# Mothership Rate Checker releases

Mothership Rate Checker is a desktop tool that fetches Mothership freight rates for a batch of shipments.

The Windows app updates itself from this repository: when it opens, it checks the latest release here and installs a newer version automatically. This repository holds release downloads only and contains no source code.

First install: download `Mothership-Rate-Checker-win-x64.zip` from the [latest release](../../releases/latest), unzip it and run `Mothership Rate Checker.exe`.
